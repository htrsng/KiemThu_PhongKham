# BUG-001 — Mất thông báo khi đăng nhập sai mật khẩu

| Trường | Giá trị |
| --- | --- |
| Module | Đăng nhập |
| Severity | Medium |
| Priority | P1 |
| Trạng thái | Closed |
| Phát hiện | 06/11/2026 |
| Regression test | `testing/e2e/cypress/e2e/login.cy.js` |

## Mô tả

API trả HTTP 401 đúng kỳ vọng nhưng interceptor chuyển hướng trang đối với mọi 401,
làm mất thông báo lỗi trên form đăng nhập.

## Kỳ vọng

Form hiển thị thông báo email hoặc mật khẩu không chính xác và không tạo phiên đăng nhập.

## Kết quả xử lý

Đã giới hạn xử lý chuyển hướng 401 cho tài nguyên được bảo vệ; lỗi từ đăng nhập/đăng ký
được trả về form. Lần chạy lại đạt 5/5 Cypress và 8/8 API.

## Bằng chứng và hồi quy

Lần CI ban đầu: [run 42178677113](https://github.com/htrsng/KiemThu_PhongKham/actions/runs/42178677113), API 8/8 đạt nhưng Cypress 4/5 do form mất lỗi sai mật khẩu.

Sau sửa: [run 42179238371](https://github.com/htrsng/KiemThu_PhongKham/actions/runs/42179238371), commit `6946c09bde0ce5c45c27e9879c056da9a29bba99`, API 8/8 và Cypress 5/5 đạt trên Ubuntu, Node.js 24, MongoDB 7, Electron headless.

Lần local 13/11/2026 tiếp tục xác nhận ca sai mật khẩu: HTTP 401, form giữ thông báo và không lưu token. Xem [kết quả Cypress](../evidence/2026-11-13/cypress-results.json).
