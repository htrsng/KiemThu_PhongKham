# QA documents

- `test-cases/`: original academic test data, case lists and spreadsheets.
- `generators/`: legacy scripts used to generate those documents.
- Other reports are retained as historical material.

Some generators randomly assign execution statuses, tester names and dates. Those fields are synthetic and must not be cited as actual test results. Do not run the generators over selected evidence. A future execution report should record the commit, environment, command or manual steps, expected and observed results, and evidence location.

Vietnamese document names are retained to keep academic references identifiable. New source files follow the repository conventions.
