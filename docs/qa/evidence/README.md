# QA evidence

Thư mục này dành cho bằng chứng chạy test như log, ảnh chụp màn hình, video và
report được chọn lọc. Không commit credential, token, dữ liệu bệnh nhân thật hoặc
file môi trường.

Artifact CI hiện được lưu trong GitHub Actions với tên `clinic-qa-evidence`; liên kết
và phạm vi của lần chạy được ghi trong [verification.md](../verification.md) và
[test-report.md](../test-report.md).
