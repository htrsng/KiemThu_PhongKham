# Postman API testing

Import these files into Postman:

- `smilecare-qa.postman_collection.json`
- `smilecare-qa.postman_environment.json`

Select **SmileCare QA - Local**, fill only local QA credentials, then run the collection in this order:

1. Authentication
2. RBAC
3. Appointments and Check-in
4. Invoices and Payments

Before running appointment requests, set `patientId`, `doctorId`, `serviceId`, `futureStartTime`, and `futureEndTime` to records in the QA database. The collection stores generated `adminToken`, `doctorToken`, `receptionToken`, `appointmentId`, and `invoiceId` in the selected environment.

The collection checks status codes, JSON shape for successful responses, role restrictions, and response time below 1500 ms. `expiredToken` is intentionally blank because an expired JWT must be generated by a short-lived test setup; the invalid-token case is runnable immediately.

Do not export a populated environment, real tokens, production URLs, or production credentials.
