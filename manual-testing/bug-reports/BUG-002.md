## Tiền điều kiện và bước tái hiện

1. Đăng nhập Admin trên DB QA.
2. Chuẩn bị một lịch hẹn riêng ở trạng thái `Đã hoàn thành`.
3. Gửi `PATCH /api/appointments/:id` với body `{"status":"Đang điều trị"}`.
4. Gọi `GET /api/appointments/:id` để kiểm tra dữ liệu đã lưu.

**Expected:** HTTP 400; trạng thái vẫn `Đã hoàn thành` theo quy tắc không lùi trạng thái trong test plan.

**Actual:** HTTP 200; GET trả trạng thái `Đang điều trị`. Lỗi làm hồ sơ điều trị đã hoàn tất có thể quay lại trạng thái đang xử lý.
